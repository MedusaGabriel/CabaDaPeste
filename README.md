# 📘 Projeto *CabaDaPeste*

**CabaDaPeste** é um jogo 3D desenvolvido com base na figura histórica de **Lampião**, utilizando as ferramentas **Unity** e **Blender**.  
O projeto foi realizado no contexto acadêmico com o objetivo de proporcionar aprendizado prático em desenvolvimento de jogos, e foi o **vencedor da GameJam UNINASSAU 2025**.

O jogo apresenta um sistema de progressão por fases e é inspirado em títulos como *Vampire Survivors*, com visual isométrico e opção de câmera em terceira pessoa. Ao longo do desenvolvimento, foram aplicados conceitos de design de fases, programação de sistemas, criação de assets 3D e pesquisa temática.

## 🎮 Sobre o Desenvolvimento do Jogo

O enredo acompanha **Lampião** em uma missão para resgatar **Maria Bonita** em uma cidade amaldiçoada — este é o plot principal do jogo.

O tempo de desenvolvimento foi de aproximadamente três meses. Entretanto, por estar em fase inicial de aprendizado, o projeto teve início um pouco antes do prazo oficial, com foco no estudo da Unity e na familiarização com Git e GitHub.

Esse projeto representou uma etapa importante na minha jornada como desenvolvedor, com diversas noites dedicadas ao seu desenvolvimento e refinamento. Apesar de ainda existirem aspectos que poderiam ser aprimorados, o jogo foi finalizado dentro do prazo e superou as expectativas iniciais.
